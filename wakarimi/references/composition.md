# 構造の合成

一つの問いへ答える主構造を選び、残る問いに必要な関係だけを加える。

## 合成するか判断する

1. 中心の問い、答えを左右する条件、補足でよい情報を分ける。
2. 主構造だけで答えられるなら、そこで止める。
3. 必要な関係が残る場合、注記・列の追加・小さな補助表・別図の順序に縛られず、最も読みやすい追加方法を選ぶ。
4. 同じ対象の属性追加で済むなら、複数図へ分けない。異なる関係・尺度・粒度が混ざって読めなくなるなら、図を分ける。
5. 分けた表現を対象IDや工程IDで対応づけ、別図を探さなくても結論と重要な条件が分かるようにする。

## 対応を保存する

| 対応 | 守ること |
|---|---|
| 対象 | 同じ対象には同じ名前・ID。別時点の状態は時点を付ける |
| 範囲 | 全体・部分・抜粋を区別し、省略した範囲を示す |
| 関係 | 包含・依存・因果・論拠を同じ線の意味へ混ぜない |
| 量 | 単位、分母、集計粒度、観測期間を揃える |
| 共有 | 複数の枝やループが共有する対象を一つの対象として保持する |
| 不確実性 | 概要にしても仮説・欠測・予定が確定情報へ変わらないようにする |

## 再帰的に分解する

- 問いに答えるために説明不足の対象だけを、一段ずつ分解する。
- 下位の問いにも、対象・属性・関係・成立条件・最小表現の判断を適用する。親と同じ図型へ固定しない。
- 各分解で新しい理解や判断が得られるかを確かめる。言い換えだけを増やさない。
- 必要な判断・担当・測定・次の行動が特定できたら止める。情報不足で進めない箇所は不明事項として残す。
- 枝の深さや子の数を揃えるために項目を追加しない。複数親や循環を無理に切って木へ戻さない。
- 詳細を折り畳む場合も、決定を変える例外・依存・条件は概要へ残す。

## よく使う組合せ

| 問い | 主構造と補助 | 検査 |
|---|---|---|
| 構成要素ごとの費用を比較する | 部分全体の構成＋費用表 | 共有費の二重計上、集計粒度、合計の一致 |
| 工程のどこで問題があるか | 工程の順序＋状態・根拠・対策の表 | 工程IDの対応、未実施と不明、局所対策の全体への影響 |
| 施策を比較して実行順を決める | 条件付き比較＋採用案の依存 | 比較結果を根拠のない効果保証や順序へ変換しない |
| 学習結果を次の行動へ反映する | 一回の手順＋次回への戻り | 反復の単位、戻す情報、成果の未測定 |
| 時点別の位置づけを比べる | 属性の比較＋時点別表示 | 同じ軸・尺度・対象ID、欠測時点、予定と実績 |
| 複数の循環へ介入する | 相互作用の全体図＋介入一覧 | 共有変数、遅延、外部条件、他ループへの作用 |

## 終了時の確認

概要から中心の問いに答え、詳細から根拠と例外を確かめられることを確認する。各表示で同じ対象を追跡し、数値・分類・時点・関係の食い違いがあれば直す。複数図が必要な理由を短く説明できなければ、統合・削減を検討する。
