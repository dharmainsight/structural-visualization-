# 視覚表現の規則

表示が追加してしまう意味を点検する。読み取れない図は、表・文章へ戻してよい。

## 視覚変数に意味を割り当てる

| 表現 | 使える意味 | 検査 |
|---|---|---|
| 位置 | 尺度上の値、順序、グループ | 自由配置と測定座標を区別する。座標なら軸・単位・範囲を示す |
| 長さ | 共通基準からの量 | 棒の長さで量を比較するなら原則ゼロ起点にする |
| 面積 | 非負の量 | 面積を値に比例させる。円の半径を値に比例させない |
| 色相・形 | 区分、所属 | 凡例か直接ラベルを付け、根拠のない順位を示さない |
| 明暗・濃淡 | 順序、量 | 順序と範囲を一定にする。意味のある中点があるときだけ発散色を使う |
| 囲み・近さ | 所属、まとまり | 囲みを包含と読ませてよいか。近さを類似度と誤読しないか |
| 線・矢印 | 接続、依存、受渡し、遷移、因果仮説 | 線の種類と方向の意味を明示し、関係型を混同しない |
| 破線・記号・注記 | 仮説、予定、欠測、省略 | 凡例を付ける。薄い色だけで不確実性を示さない |

一つの変数へ複数の意味を割り当てすぎない。同じ意味には同じ表現を使い、異なる意味はラベルでも区別する。

## 数値と尺度

- 単位、観測時点、集計単位、分母を揃える。変換した値には変換後の単位を示す。精度の根拠以上の桁を出さない。
- カテゴリの並びに距離や比率を与えない。低・中・高を等間隔の実測値として扱わない。
- 折れ線や散布図で軸範囲を絞る場合は範囲を明示し、差の大きさを量の比と混同させない。軸切断は目立つ形で示す。
- 対数軸は変換と読み方を示し、通常の対数でゼロや負値を配置しない。根拠なく値を落としたり置換したりしない。
- 比較する複数図は共通尺度を優先する。異なる範囲・基準が必要なら明示し、同じ位置の直接比較を避ける。
- 割合の内訳は分母と排他性を確認する。複数回答やタグの割合を合計100%の円や積上げへ変換しない。
- 欠測をゼロにしない。折れ線の欠測区間を補間するなら方法と仮定を示す。信頼区間・ばらつきの種類は資料にある場合だけ表示する。
- 二重軸、立体効果、面積表現を重ねる前に、同じ情報を表や分図で明瞭に伝えられないか検討する。

## 接続と分岐

- 矢印を文章へ戻して読む。「AがBに必要」「Aの後にB」「AがBを増やす」は別の関係として検査する。
- 条件分岐には条件を付ける。AND（すべて必要）とOR（いずれかでよい）が入力から確定する場合は区別する。
- 共有対象は同じIDで示す。表示上複製する場合は参照であると分かるようにし、件数や量へ重複計上しない。
- 省略した工程や経路があるなら範囲を示す。到達経路・戻り・依存を装飾のために追加しない。
- 因果の正負は変化の向きであり、良し悪しの色分けと混同しない。

## 読みやすさと媒体

- タイトルは読者の問いや図の内容に合わせる。結論が未確定なら結論形のタイトルで断定しない。
- ラベルを対象の近くに置き、短く一意にする。略記が必要なら元の名称を対応表へ残す。
- 色だけに依存せず、文字・形・線種を併用する。背景との判別が難しい薄色や、赤緑だけの区別を避ける。
- 小さな画面や拡大表示で文字が読めるか、重なり・切れ・長い横方向の追跡がないか確認する。無理な縮小より分図や縦配置を選ぶ。
- インタラクションを使う場合も、重要情報をホバーだけに隠さず、タップ・キーボードや表でも参照できる形にする。
- 意味がある画像には短い読み方または代替説明を付ける。必要な数値は元データ表へたどれるようにする。

## 描画と確認

1. まず対象・関係・値を確定し、表現に対応させる。
2. 正確な構造図は、編集可能なMermaid・SVG等で作る。定量グラフはプロット用の道具を使う。生成画像を正確な数値や文字配置の検証手段にしない。
3. Mermaidでは単純な対応だけなら表や文章を検討する。横に長い図は縦配置や分図にし、記号を含むラベルを引用符で囲む。利用環境が対応する記法を使う。
4. 描画できる環境なら実際に描画し、文字・線・凡例・軸・数値を点検する。解析成功だけで見た目の確認を済ませない。
5. 描画を確認できない場合、未確認であることを必要に応じて示す。利用環境が記法に未対応なら読み取れる代替表現を返す。
