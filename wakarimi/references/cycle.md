# 反復とフィードバック

入力: 読者の問い、反復単位、状態・活動・変数、戻りの関係、時点と根拠。
出力: 反復または戻りの経路、反復間の変化、因果仮説と観測の区別、必要な外部条件・遅延。

## 1. 戻りの意味を識別する

| 関係 | 成立に必要な情報 |
|---|---|
| 定期的な反復 | 同じ役割の活動・状態が次の回にも現れること |
| 結果を使った調整 | 結果や観測値が後続の判断・行動へ反映される経路 |
| 因果的なフィードバック | 因果関係をたどり、元の変数の後続状態へ影響が戻る経路 |
| 類似パターンの再現 | 時点間で比較できる共通点、差異、背景条件 |

単なる定期実行を学習や改善と呼ばない。相関や双方向の連絡だけで因果閉路を確定しない。歴史的な類似から一定周期、必然的な進歩、将来の再現を保証しない。これらの関係は併存し得るため、問いに必要なものを選ぶ。

## 2. 反復単位と状態変化を定める

1. 何を一回と数えるか、各回の開始・終了、観測時点を定める。
2. 各回の開始状態、活動・介入・外部条件、結果、次回の変更を対応づける。時点そのものが過去へ戻るとは表現しない。
3. 変化を比較する属性、測定方法、基準を揃える。未測定なら反復の事実だけを示す。
4. 速度、誤り、負担などの方向が一致しない場合は、それぞれを保持する。一つの「成長」へ縮約しない。
5. 目標値や許容範囲を維持する仕組みでは、逸脱と調整を示す。調整の意図と観測された安定性を区別する。

螺旋や段階図は、反復間の差が問いの中心で、通常の比較表より読み取りやすい場合に限る。半径、高さ、間隔へ数量を割り当てるなら尺度を示す。装飾によって単調な向上や必然性を含意しない。

## 3. 因果の戻りを検査する

1. 変数の定義・単位・対象範囲を揃え、矢印が表す関係を明示する。順序、情報の受渡し、依存、因果を同じ意味の矢印に混ぜない。
2. 各因果辺の根拠、成立条件、必要な時間遅れを確認する。未確認の辺は仮説と表示し、方向も不明なら確定した矢印を置かない。
3. 閉路をたどり、最後の影響が最初の変数の後続状態へ戻ることを確認する。戻りがなければ開いた経路として示す。
4. 複数の経路で共有する変数は同じ対象として保つ。別図へ分ける場合も共有IDと接続関係を示す。
5. 外部入力、制約、飽和、遅延、別ループとの相互作用が結論を変える場合は保持する。

増減方向を扱う場合の正負は、他条件が等しいときの局所的な影響方向とする。各辺の符号が同じ条件下で定まる閉路では、負の辺が偶数なら自己強化、奇数なら均衡化の方向と判定する。符号不明、非単調、条件依存なら判定を留保する。

自己強化を好循環、均衡化を安定と同一視しない。方向の分類だけで効果、安定性、将来の軌道を予測しない。

## 4. 介入を検討する

変更する変数・関係、期待する変化、副作用、観測指標、検証条件を対応づける。複数ループがある場合は、局所の対策が共有変数を通じて他へ与える影響も調べる。一つの要因を除けば全体が必ず解決すると断定しない。

## 5. 表現と停止条件

| 読者の問い | 表現候補 |
|---|---|
| 何を繰り返すか | 短い手順、反復条件付きの工程図 |
| 各回で何が変わったか | 反復別の比較表、時系列グラフ |
| 結果が何を変えるか | 反映先を示す工程図、対応表 |
| 相互作用がどう戻るか | 因果ループ図、関係一覧、ネットワーク |

一方向の説明だけで問いに答えられるなら、それを使う。反復の対象、戻りの意味、根拠、状態変化、未確認事項が読み取れれば止める。省略で結論が変わる経路は残す。

## 6. 適用例

- 毎月棚卸しをするだけなら定期反復として示す。結果を次回の補充量へ反映する規則があれば、その戻りを加える。
- 施策と評価を毎週繰り返していても、成果値がなければ改善実績とは述べない。
- 待ち時間の増加が苦情を増やし、苦情対応が処理能力を下げるという説明は、裏付けがなければ各辺を仮説とする。
- 在庫に応じて補充量を減らす規則は調整方向を示すが、納入遅れや需要変動がある場合の安定性までは保証しない。
