# 開発計画・進捗（正本）

更新: 2026-11-27

## 目的
情報の意味的関係を保ったまま、人間が理解・比較・判断しやすい最小の表現へ変換する。装飾的な可視化や特定経営手法の暗記は目的としない。

入力: 質問、文章、データ、分析結果。出力: 文章、一覧、表、図、グラフ（利用可能な媒体に適応）。外部接続はスキル実行に必須としない。

## 次の入力（第1回）

## 更新ルール
各資料を受領後、出典台帳・定義・判断規則・評価ケース・本計画の該当箇所を同じPRで更新する。確認済みと未確認を明示し、主張の変更は根拠を残す。公開リポジトリには本文やスクリーンショットを保存しない。段階完了時に差分を確認し、ユーザーがマージを判断する。
