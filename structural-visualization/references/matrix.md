# 属性と尺度

入力: 読者の判断・探索の問い、対象ID、属性の定義、観測時点、値・単位・測定方法・不明事項。
出力: 同じ条件で比較できる表または図、尺度と判定基準、必要な欠測・不確実性。

## 1. 比較と探索を区別する

- 比較・選択では、判断に必要な属性と必須条件を先に定める。二つの属性を読ませるだけなら表で足りるか確認する。
- 関係探索では、変数間の傾向と例外を調べる。相関しそうな変数を選ぶこと自体を誤りとしない。
- 組合せ、位置、分布を読む価値がある場合に二軸を使う。二軸へ減らすことで必須条件が消えるなら、表や複数図を使う。

## 2. 軸の重複を検査する

比較では定義、単位変換、算出式、構成要素を調べ、同じ情報を別の評価軸として二重計上しない。完全に同じ情報の変換なら、軸の置換または一次元への縮約を検討する。

相関があることだけで軸を排除せず、組合せに判断上の追加情報があるか確認する。この非冗長性を統計的な独立性と混同しない。データ不足で独立性を断定しない。探索でも、単位変換で生じた関係を新しい発見として扱わない。

## 3. 尺度を定義する

| 属性の性質 | 保持する意味 | 仮定しない意味 |
|---|---|---|
| 順序なしの区分 | 同じ・異なる、所属、組合せ | 大小、距離、中間点 |
| 順序のある区分 | 前後・高低の順序 | 等間隔、差の量、比率 |
| 数量 | 定義と単位に沿った差・大きさ | 定義・集計粒度の異なる値の直接比較 |
| 判断による評価 | 判定基準、評価者、理由、不確実性 | 根拠のない精密な点数や座標 |

数値コードを付けても尺度は変わらない。数量でも比率を解釈できるかはゼロ点の意味を確認する。合成指標には計算方法・重み・根拠を示し、重みや欠測の扱いで結論が変わる場合は条件付きの判断にする。

区分境界は端点の所属まで定める。数量を区分へ丸めた場合は、区分内の具体値の差など、表示から失われる情報を短く示す。詳細な比較が必要なら元の値も保持する。測定値、推定値、計画値、発想用の仮置きを区別する。根拠のない値は作らず、必要なら測定・判定の方法を提案する。

## 4. 表現を選ぶ

| 関係 | 表現候補 | 確認すること |
|---|---|---|
| 区分と区分 | クロス表、所属表 | 区分数を定義に合わせ、2×2へ固定しない |
| 区分と数量 | 集計表、点や棒、分布 | 区分間に量的な距離を付けない |
| 数量と数量 | 散布図、数値表 | 軸の単位・範囲・方向・時点を揃える |
| 順序・定性評価を含む比較 | 基準付きの表、順序を保った帯 | 等間隔や精密位置を測定結果として示さない |
| 多数の属性・時点 | 比較表、同じ尺度の複数図 | 対象ID、必須条件、比較尺度を保つ |

- ゼロ、観測上の該当なし、欠測、非適用を区別する。空欄だけで意味を兼ねない。
- 比較図の各軸は、値が増える向きと判断上望ましい向きを区別して示す。後者は目的や指標定義から決め、不明なら未定のままにする。
- 図の境界線や象限名は、合意した基準または判断上の理由がある場合に付ける。図の中央を自動的に良否の境界にしない。
- 属性を色や大きさに追加する場合は、その尺度に適した表現か確認する。読み分けが難しければ別表・別図へ分ける。
- 比較する図では軸と尺度を共有する。別の尺度が必要なら明示し、見た目の位置や傾きだけで横断比較させない。

## 5. 結果を点検する

観測範囲、標本、定義、欠測、測定誤差を確認する。傾向と例外を残し、外れた値を理由なく除かない。相関だけで原因・効果を断定しない。定量図の値は入力と照合し、集計・単位換算・計算は可能ならコードで検算する。

読者の判断に必要な差、軸の重複、境界の妥当性、省略属性の影響を確認する。必須条件の未達を、別属性の高得点で相殺しない。

## 6. 適用例

- 費用を円と千円の二軸に置く案は一つの費用軸にまとめ、別の判断情報が必要か検討する。
- 「低・中・高」の評価は順序付きで示し、「高は低の3倍」と計算しない。
- 処理時間を「10秒未満」「10秒以上」に分ける場合、10秒は後者だけに含める。
- 費用は既知でも効果が未測定の候補は「効果未測定」と残す。効果ゼロの候補と同じ位置に置かない。
