# 二次元化：軸選択と表現の操作規則

出典: S01-4（第4章の基本5項目）。原典の要点は [sources.md](sources.md) に記録。以下の判定手順、尺度の形式化、描画条件、例は PROPOSAL（独自設計）。実践編の個別手法は未確認。

## 1. 目的を識別する
- 比較・判断: トレードオフ、位置づけ、資源配分などの問いに対し、互いに異なる判断情報を与える2属性を選ぶ。
- 探索: 2変数の関係、予想に反する観測、関係の有無を調べる。相関しそうな変数を意図的に選ぶことも許容する。
- 2項目を並べて読むだけなら比較表等で十分。二次元の位置・組合せ・分布を読むことに利点がある場合に選ぶ。

## 2. 軸の非冗長性を検証する
比較・判断では、定義、算出式、構成要素、観測分布を点検する。同じ情報の言い換え、単位変換、合成指標とその成分の重複に注意する。両軸に相関があることだけで無効とせず、組合せに判断上の追加情報があるか確認する。完全な関数従属なら軸の置換か一次元への縮約を検討する。

ここでいう非冗長性は統計学上の確率的独立性と同一ではない。観測数が少ない、データが未提示の場合は独立性を断定しない。探索では相関の有無・例外の発見が目的になり得るため、非冗長性を一律の前提としない。ただし同一指標の変換を発見した相関として報告しない。

## 3. 各軸の尺度と測定根拠を定義する
| 軸の性質 | 有効な表現 | 禁止する解釈 |
|---|---|---|
| 順序なしの区分 | セルへの分類、クロス集計 | 区分間の距離・大小・中間点 |
| 順序のある区分 | 順序を保つセル・帯 | 等間隔、比率、差の量を自動的に仮定 |
| 定量的な値 | 単位・目盛・範囲を示す座標 | 定義や単位の異なる数値の直接比較 |
| 定性的な評価 | 根拠ある順序、範囲、明示した判断基準。合意前の概念図は暫定表示 | 恣意的な精密座標、測定値であるかのような表示 |

原典の区分軸・連続軸（定量・定性）を実装上の尺度に展開した。定性的な評価で中間点を想定できても、間隔の等しさや算術演算の妥当性までは保証されない。数値コードや採点は量的尺度の証明ではない。各軸は個別に判定する。定量値を区分へ変換する場合は境界、端点の所属、区分による情報損失を明示する。

入力として対象、観測時点、軸の定義、単位・方向、測定方法、値または分類根拠、不明値を保持する。合成指標には算出方法・重み・根拠を付す。観測不能なら精密配置をせず、評価基準を提案するか不明のまま示す。

## 4. 最小の表現を選ぶ
- 区分×区分: クロス表・カテゴリ行列。2×2に固定せず、定義で有効な区分数にする。空セルと不明セルを区別し、セル内の点位置に意味を付けない。
- 区分×定量: グループ別の点・分布・集計表。区分間の数値距離を示唆しない。
- 定量×定量: 散布図等。比較の問いに必要な場合のみ根拠ある境界を示す。軸方向・範囲・単位、観測時点、欠測を確認する。
- 定性評価を含む: 基準・判定者・根拠・不確実性を添えた帯、区分または表。内部の発想用と第三者への説明用を区別する。
- 3属性以上: 主目的に適した軸を選び、残りは注記・表・複数の2軸図等で保持する。比較図では共通軸・尺度・対象IDを揃える。第三属性を省くことが結論を変えるなら省略しない。立体描画は理解上の利点が検証できる場合に限定する。

## 5. 探索・比較の結果を検証する
探索では観測範囲、標本、変数の定義、欠測、測定誤差を明示し、分布の傾向と例外を区別する。外れた観測は誤りと決めつけず、検証対象とする。相関や外れ値の存在だけで原因・効果を確定しない。データのない仮説図は実測結果から区別する。

比較では目的に関係する差、軸の非冗長性、境界の妥当性、根拠のある位置、削除した属性の影響を確認する。象限名や良し悪しを軸だけから自動付与しない。図から意図した問いに答えられなければ表や別構造に変更する。
