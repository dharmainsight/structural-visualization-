# 集合と分類

入力: 読者の問い、対象範囲、分類する単位、属性とその根拠。
出力: 共通の基準で整理した項目、所属規則、必要な未分類・重複・範囲の注記。

## 1. 分け方を決める

1. 何の一覧か、どの時点・地域・対象を含めるかを定める。手元の観測対象と、対象全体を区別する。
2. 各項目に答えさせる問いを揃える。役割・状態・原因・属性など、異なる観点を一つの分類軸に混ぜない。
3. 一つだけに所属させる分類、複数所属を許すタグ、比較の観点、式の変数を区別する。
4. 既存の制度・定義・規則を使う場合は適用範囲を確認する。目的に合わせて区分を作る場合は、所属条件を説明し、境界事例で点検する。
5. 二分法でも、中間、両方、どちらでもない、不明があり得るか確認する。区分数や名称の知名度を妥当性の証拠にしない。

## 2. 漏れと重なりを検査する

| 意図する整理 | 確認すること |
|---|---|
| 排他的で網羅的な分類 | 対象ごとの所属が一意で、すべての対象に所属先があるか |
| 複数所属を許すタグ | 各タグの意味と所属条件が明確で、重なりを保持しているか |
| 主要項目の抜粋 | 選択基準と対象範囲を示し、全体を列挙したと誤認させないか |
| 式による分解 | 演算、単位、分母、集計粒度が一致し、項目を実際に合算できるか |

- 相互排他・全体網羅は、排他的な集合分割を目的とするときに要求する。原因候補、複数の視点、タグに一律に要求しない。
- 「その他」は既知の残余、「不明」は情報不足、「未調査」は観測範囲外として区別する。「その他」を置くだけで網羅性を保証しない。
- 既知の反例を残し、所属条件の修正、別軸の追加、階層化を検討する。分類に合わせて対象の意味を変えない。
- 件数や割合を出すときは単位と分母を揃える。重複所属の合計を人数や排他的な内訳として扱わない。

## 3. 読める形にまとめる

- 短い独立項目は一覧、同じ属性を比較する対象は表、意味のあるまとまりは見出し付きの群にする。
- 項目名の観点・品詞・粒度を揃える。語呂や略称のために内容を変えない。
- 同列の項目は同程度の書式で示す。大小、並び順、色が優劣を意味する場合は、その基準を明示する。
- 項目数に一律の上限を設けない。量が多ければ概要と詳細を分け、必要な項目を保持する。
- 依存、親子、位置関係が回答に必要なら、その関係を表せる構造を併用する。平坦な一覧へ押し込まない。

## 4. 適用例

- 複数回答の利用目的を整理する場合は、利用者一人に複数のタグを認める。各割合の分母を利用者数とし、合計が100%を超え得ることを示す。
- 必須の点検項目が12個ある場合は、設備・記録・復旧などのまとまりを作り、12項目すべてを残す。
- 「配送費＝重量×単価」の重量と単価は乗算の変数として示す。配送費の加算的な内訳にはしない。
- 顧客を「新規・既存」に分ける場合は、判定時点と新規の期間を決める。休眠は別属性なのか独立区分なのかを先に定義する。

## 5. 終了確認

対象範囲、所属条件、粒度、重複の扱い、未知の項目を確認する。読者が必要な対象を見つけ、分類から許される比較だけを行える状態で止める。
