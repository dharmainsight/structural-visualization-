# 5構造の操作定義

基本的な着想は S01-1 で確認済み。並列化の分類根拠と5要件は S01-2、対概念の関係の違いと階層化の基本は S01-3a で確認済み。以下の形式化・成立条件・表現候補・合成は PROPOSAL。第3章の後続節と残りの各章の基本説明を確認後に更新する。5構造は意味的関係の実用的な候補であり、数学的に相互排他・網羅的であることは未証明。

| ID | 入力関係 | 目的 | 成立・確認条件 | 不適用例 |
|---|---|---|---|---|
| parallel | 共通基準で並ぶ分解要素または分類 | 全体の把握と網羅性の点検 | 基準の根拠・対象範囲・粒度が明確で、欠落と重複を検討できる | 原因や順序を平坦化する、列挙・図示・権威を完全性の証拠とみなす |
| hierarchy | 水準差を持つ関係（部分全体、型と下位型、目的手段、根拠主張など） | 水準別の分解・体系化 | 関係型、同じ親の子の粒度、範囲、完全性の意図が明確 | 対語だけで上下を決める、異なる水準を網羅的な同列項目とする、多対多を単一親に強制する |
| matrix | 2属性と対象 | 比較、位置・関係の把握 | 軸の定義・尺度・値の根拠が明確 | 定性分類を根拠なく数値化する |
| sequence | 順序、時刻、遷移、依存 | 過程と進行の理解 | 順序の種類と分岐・並行を明示 | 相関から順序や因果を捏造する |
| cycle | 戻りを含む関係または反復過程 | 均衡、状態変化、フィードバックの理解 | 戻り・反復の仕組みと条件が根拠で支持される | 単なる反復を因果や改善の証拠にする |

## 関係の識別（対概念）
同じ二項形式でも、同水準の対比・上下の水準差・過程の順序は異なる。語の並びや対立の印象ではなく、読者の問いと根拠のある関係から選ぶ。単語対だけで相互排他・網羅性・因果・上下を確定しない。詳細は [hierarchy.md](hierarchy.md) を参照。

## 構造と図型の分離
同じ見た目でも線が表す関係は異なり得る。分岐図を選ぶ前に、同列の要素を並べるのか、多段の親子関係を示すのかを決める。表に2つの評価項目が存在するだけでは、位置づけを主目的とする二次元化とは限らない。閉じた矢印を描く前に、反復または戻りを確認する。

## 円環の暫定的な下位区分
- 均衡維持型: 許容範囲や基準を保つ仕組みを示す。
- 発展型: 反復ごとに変化する状態と、その変化方向を根拠に基づき示す。
- 悪化型: 反復が悪化を増幅する条件を示す。
- 未判定型: 反復は確認できるが、状態変化の方向や効果は不明。

均衡と発展への着目は原典確認済み。上記の4区分および判断条件は独自拡張。螺旋は単なる装飾にせず、反復間の変化を表す場合に使用する。

## 合成例
- 階層×並列: システムの構成を親子で整理し、同階層で属性を比較する。
- 時系列×円環: 工程の順序を示し、評価結果が次回計画へ戻る経路を示す。
- 二次元×時系列: 各時点の観測値に基づく位置変化を示す。時点不明や推定値を区別する。

図を作らない選択、ネットワーク・地理など別構造を使う選択も許容する。
