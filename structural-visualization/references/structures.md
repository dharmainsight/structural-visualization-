# 構造の選択と境界

形から選ばず、問いに答えるために保持すべき関係から選ぶ。

## 入力を整える

必要な情報だけを次の形で保持する。簡単な依頼で表や中間データの提出を義務にしない。

| 要素 | 保持する内容 |
|---|---|
| 問い | 読者が決めること、理解すること、実行すること |
| 対象 | 対象範囲、一意に区別できる名前、時点 |
| 属性 | 値、単位、尺度、定義、欠測 |
| 関係 | 始点と終点、関係の種類、方向、条件、根拠の状態 |
| 制約 | 必須情報、例外、媒体、長さ、未確認事項 |

## 選択手順

1. **直接回答を検討する。** 単一事実や短い説明で問いに答えられるなら終了する。
2. **落とせない関係を選ぶ。** 判断条件や例外を除くと結論が変わるなら主構造または明示的な補助情報に残す。
3. **成立しない表現を除く。** 未測定値の精密座標、多重所属の単一親ツリー、並行工程の直列化、証拠のない因果閉路は選ばない。
4. **問いに最も直接答える候補を選ぶ。** 比較なら同じ属性を対照できる表、手順なら依存と分岐が追える表現など、読む作業から決める。
5. **必要な情報を全部保持できるか点検する。** 二軸への縮約や概要化で必須条件が落ちる場合、別表・注記・分図で保持する。
6. **読み取り負荷で候補を絞る。** 対象を探す、見比べる、関係をたどる回数が少ないものを選ぶ。同程度なら短い表現を選ぶ。
7. **不足の重大さを判定する。** 結論や構造が逆転する不足だけを確認する。部分的に答えられるところは先に示す。

自動的な点数づけや固定の図の順位は使わない。利用者が形式を指定した場合も、意味を保てる範囲で従い、必要な制約を示す。

## 関係ごとの成立条件

| 関係 | 適用条件 | 出力で保持すること | 合わない場合 |
|---|---|---|---|
| 集合と分類 | 共通基準で所属・並列性を説明できる | 全体の範囲、基準、重複、未分類、抜粋か全体か | 依存や親子が中心なら平坦化を避ける |
| 包含と分解 | 水準の異なる対象の関係を説明できる | 親子の述語、同水準の粒度、共有要素 | 複数親は対応表や有向グラフ、循環はネットワーク |
| 属性と尺度 | 対象と比較基準・観測値が対応する | 単位、時点、欠測、必須条件、尺度 | 未測定なら基準案と不明を示し、数値を作らない |
| 順序と依存 | 前後・必要条件・状態遷移を説明できる | 分岐、並行、合流、開始・終了、順序不明 | 日時がなければ等間隔の時間軸を装わない |
| 反復とフィードバック | 同種の過程の再実行、または次の状態への戻りがある | 一回の範囲、戻りの内容、効果と不明、外部条件 | 戻りがなければ開いた工程、相関だけなら関連表 |

## 境界で迷う例

| 入力の見た目 | 問うこと | 選ぶ関係 |
|---|---|---|
| 「設計・実装・検証」という三語 | 各担当の役割の違い | 共通属性での比較 |
| 同じ三語 | 何が終われば次へ進めるか | 依存と開始条件 |
| 「目標・施策・作業」という三語 | どの作業が何に寄与するか | 目的と手段の対応。効果は別途検証 |
| 表に費用と重量がある | 正確な値と条件で候補を選ぶ | 比較表。二属性だけで散布図を義務にしない |
| 毎月の同じ作業 | 次の実施日を知る | 予定一覧。循環因果を付加しない |
| 複数対象間に戻りがある | 連絡先を把握する | 通信・依存ネットワーク。因果の証明にはしない |

地理的な位置、数値の分布、区間の重なり、多対多の対応などは、地図・分布図・期間表・対応表等を選ぶ。候補集への当てはめ自体を目的にしない。
