# Structural Visualization

意味構造を認識し、人間の理解を支援する最小限の表現を選択する ChatGPT スキルの開発プロジェクト。

## Purpose

- 情報の関係を識別し、並列・階層・二次元・時系列・円環の5構造を使い分ける。
- 必要な場合だけ図表を用い、文章で十分な場合は文章を選ぶ。
- 視覚的な整然さを理解や正確性の証拠とみなさず、個別の経営フレームワークに依存しない領域横断的な操作規則へ抽象化する。

## Development

開発計画・進捗・原典確認状況は `docs/PLAN.md` を正本とする。スキルは `structural-visualization/SKILL.md` に実装する。

着想元: 手塚貞治『武器としての戦略フレームワーク』（日本実業出版社）。表紙・目次および第1章の5分類の説明・概念図を確認済み。各論は未確認。著者の説明と独自の操作規則を区別する。

公開リポジトリには書籍の本文、スクリーンショット、図表の複製を掲載しない。出典情報と独自の抽象化・検証用事例のみを登録する。
